[The Long Roast](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544).

> My agent writes 400 lines to fix a typo, then calls the diff 'a small cleanup' and waits for praise.

## Run it

```sh
npx tsx main.ts
cat /output/entry.txt
```

The program writes the fixed line (100 characters, one line) to `/output/entry.txt`.
